# SimpleCalc

Full-stack scientific calculator built with React (Vite) frontend and Express backend.

Quick start

1. Frontend

```
cd frontend
npm install
npm run dev
```

2. Backend

```
cd backend
npm install
npm run dev
```

Docker

```
docker-compose up --build
```

Frontend is configured for GitHub Pages (`base: '/SimpleCalc/'` in `vite.config.js`).
