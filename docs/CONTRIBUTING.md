# Contributing Guide

Thank you for contributing to SimpleCalc.

---

# Development Workflow

## 1. Fork the Repository

Create your own fork of the project.

---

## 2. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/SimpleCalc.git
```

---

## 3. Create a Branch

```bash
git checkout -b feature-name
```

---

## 4. Make Changes

Implement your feature or fix.

---

## 5. Commit Changes

```bash
git commit -m "Add feature"
```

---

## 6. Push Changes

```bash
git push origin feature-name
```

---

## 7. Open Pull Request

Submit a pull request for review.

---

# Code Guidelines

- Use clear naming conventions
- Keep components modular
- Avoid duplicated logic
- Follow consistent formatting
- Write readable code

---

# Frontend Guidelines

- Use reusable React components
- Prefer functional components
- Keep styling consistent
- Use Tailwind utility classes

---

# Backend Guidelines

- Keep routes lightweight
- Use service layer for logic
- Handle errors properly
- Validate inputs

---

# Recommended Improvements

Contributors may work on:

- Graph plotting
- Better parser engine
- Persistent history
- Unit conversions
- Themes
- Keyboard shortcuts
- PWA support
- Calculator memory functions

---

# Reporting Issues

Please include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots if applicable
